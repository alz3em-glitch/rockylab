# RockyLab

Interactive Rocky Linux system administration training inspired by the RH124 lecture sequence.

- 24 progressive levels and 72 practice tasks
- Command explanations, hints, checks, quizzes, progress tracking
- Browser terminal simulator for safe practice
- Rocky lab setup guide for Cockpit and isolated SSH practice
- Public static site: https://alz3em-glitch.github.io/rockylab/

The browser simulator never runs commands on a real machine. The optional SSH gateway is documented separately and must be installed on a dedicated Rocky Linux training server with a strong bearer token and firewall allow-list.
